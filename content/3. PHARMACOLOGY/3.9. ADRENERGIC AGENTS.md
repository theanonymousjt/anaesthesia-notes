### 1.1. AUTONOMIC NERVOUS SYSTEM OVERVIEW

* **Definition**: The autonomic nervous system (ANS) is a complex system of neurons that controls the body's internal milieu [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Not under voluntary control and anatomically distinct from the somatic nervous system [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Efferent limb controls individual organs and smooth muscle, while afferent limb relays visceral sensation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Hypothalamus is the central integration point, but under neocortex control [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Local autonomic functions can occur without hypothalamic involvement:
	* Gut can coordinate secretions locally [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Some reflex activity is processed within the spinal cord [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Control of vital functions by baroreceptors is processed within the medulla [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * ANS is divided into parasympathetic and sympathetic nervous systems [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Parasympathetic Nervous System (PNS)** [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Made up of preand post-ganglionic fibers [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Pre-ganglionic fibers arise from:
	* Cranial nerves (III, VII, IX, X) - supply eye, salivary glands, heart, bronchi, upper GI tract, ureters [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Sacral fibers (S2, 3, 4) - supply distal bowel, bladder, and genitals [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Fibers synapse within ganglia close to or within effector organs [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Post-ganglionic neurons release acetylcholine acting via nicotinic receptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Modulated by anticholinergics and anticholinesterases [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Sympathetic Nervous System (SNS)** `[A:1-2]`
  * Also composed of preand post-ganglionic fibers [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Pre-ganglionic fibers arise from lateral horns of spinal cord at thoracic and upper lumbar levels (T1-L2) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Pre-ganglionic fibers pass into anterior primary rami, and via white rami communicans into sympathetic chain or ganglia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * May either synapse at that level, adjacent level, or pass anteriorly through splanchnic nerve to prevertebral ganglion [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Unmyelinated post-ganglionic fibers pass into adjacent spinal nerve via grey rami communicans [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Post-ganglionic fibers release norepinephrine acting via adrenoceptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Adrenal medulla receives presynaptic fibers that synapse directly with chromaffin cells, using ACh as transmitter [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Releases epinephrine into circulation (acts as a hormone, not a transmitter) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Post-ganglionic sympathetic fibers release ACh to innervate sweat glands (exception to typical pattern) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * All pre-ganglionic ANS fibers are myelinated and release ACh acting via nicotinic receptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Summary of autonomic neurotransmitters** [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Pre-ganglionic PNS: Acetylcholine
  * Post-ganglionic PNS: Acetylcholine
  * Pre-ganglionic SNS: Acetylcholine
  * Post-ganglionic SNS: Norepinephrine (except sweat glands: Acetylcholine)
  * Adrenal medulla: Acetylcholine (pre-ganglionic) triggers epinephrine release (no post-ganglionic transmitter)

### 1.2. NEUROTRANSMITTER DISTRIBUTION AND METABOLISM

* **Neurotransmitter distribution**:
  * Norepinephrine is released by postganglionic sympathetic fibers at end-organ tissues (except eccrine sweat glands and some blood vessels) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Acetylcholine is released by preganglionic sympathetic fibers and all parasympathetic fibers [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Norepinephrine metabolism**:
  * Synthesized in cytoplasm of sympathetic postganglionic nerve endings and stored in vesicles [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Released by exocytosis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Primarily terminated by reuptake into the postganglionic nerve ending [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * In neurons: metabolized by monoamine oxidase or repackaged into vesicles [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * In liver: metabolized by monoamine oxidase and catechol-O-methyltransferase [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * May diffuse and be taken up by nonneuronal cells to be metabolized by catechol-O-methyltransferase [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Specific reuptake mechanisms** [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Uptake 1**: Active uptake back into nerve terminal where norepinephrine is metabolized by MAO or recycled [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Forms the main mechanism by which norepinephrine is inactivated [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Uptake 2**: Diffusion away from the nerve - less important mechanism [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Norepinephrine reaches circulation this way and is metabolized by COMT to inactive VMA and normetadrenaline [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Metabolites are conjugated with glucuronic acid or sulfates and excreted in urine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Receptor regulation**: Prolonged adrenergic activation leads to desensitization and hyporesponsiveness to further stimulation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

### 1.3. SYNTHESIS OF NOREPINEPHRINE

* **Rate-limiting step**: Hydroxylation of tyrosine to dopa [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Synthesis pathway**: Tyrosine → Dopa → Dopamine → Norepinephrine → Epinephrine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Conversion to epinephrine**: Methylation of norepinephrine by phenylethanolamine N-methyltransferase [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Location of final conversion**: Adrenal medulla contains specific chromaffin cells for storing/releasing epinephrine that are different from those that store norepinephrine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

![Untitled](ADRENERGIC_ADRENERGIC_Untitled.png_99f103.png_778ba6.png)

* **Catecholamine structure**:
  * Based on a benzene ring with amine side chains attached at C1 position [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * When hydroxyl groups are present at C3 and C4 positions, the agent is known as a catecholamine (3,4-dihydroxybenzene = "catechol") [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Adrenaline (epinephrine), noradrenaline (norepinephrine), and dopamine are naturally occurring catecholamines with interrelated synthesis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

**Bottom Line:** The sympathetic nervous system primarily uses norepinephrine as a neurotransmitter, with synthesis beginning from tyrosine and termination primarily through reuptake. Understanding this pathway provides the foundation for drug action on the sympathetic nervous system.

## 2. ADRENERGIC RECEPTORS 












### 2.1. GENERAL CLASSIFICATION

* **General classification**: α and β receptors - linked to G proteins using GTP as cofactor but with unique effector systems [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Structure**: All adrenergic receptors have a similar molecular structure with 7 transmembrane segments [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Sympathomimetic drugs**:
  * Exert effects via adrenoreceptors or dopamine receptors either directly or indirectly [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Direct-acting agents attach to and act directly via receptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Indirect-acting agents cause release of norepinephrine to produce effects via receptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

### 2.2. ALPHA RECEPTORS

#### 2.2.1. Α1 RECEPTORS

* **Subtypes**: α1A, α1B, α1D [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Signal transduction**: Linked to Gq activating phospholipases [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Mechanism of action**: α1-adrenoceptor activation stimulates phospholipase C (via Gq), which hydrolyses phosphatidylinositol bisphosphate (PIP2) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Inositol triphosphate (IP3) is released, leading to increased Ca2+ availability within the cell [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Distribution**:
  * Spleen and liver contain mainly α1B receptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Heart, neocortex, kidney, was deferens, and hippocampus contain equal amounts of α1A and α1B receptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Location**: Postsynaptic activators of smooth muscle throughout the body [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Effects**:
  * **Vascular**: Constriction of resistance and capacitance vessels [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Eye**: Mydriasis (pupil dilation due to contraction of radial eye muscles) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Respiratory**: Bronchoconstriction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Cardiovascular**: Vasoconstriction (also has positive inotropic effect on myocardium) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Uterus**: Contraction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **GI/GU**: Sphincteric constriction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Metabolic**: Inhibits insulin secretion and lipolysis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Clinical note**: α1-adrenergic antagonists prevent catecholamine-induced ventricular arrhythmias [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 2.2.2. Α2 RECEPTORS

* **Subtypes**: α2A, α2B, and α2C [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Signal transduction**: Linked to Gi inhibiting adenylate cyclase [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Mechanism of action**: α2-adrenoceptor activation is coupled to Gi-proteins that inhibit adenylate cyclase and reduce cAMP concentration [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Location**: Found in preand postsynaptic membranes [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Postsynaptic effects**:
  * **Vascular**: Arterial and venous vasoconstriction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Hematologic**: Platelet aggregation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Metabolic**: Inhibition of insulin release [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **GI**: Inhibition of bowel motility [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Endocrine**: Stimulation of growth hormone release, inhibition of ADH release [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Cholinergic pathway effects**:
  * **Respiratory**: Bronchoconstriction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Exocrine**: Dry mouth (decreased salivation) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Cardiovascular**: Modulation of baroreceptor reflex (increased sensitivity), vagal mediation of heart rate (bradycardia) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Presynaptic α2 receptors**:
  * **Function**: Inhibits NE release by decreasing Ca²⁺ entry into neuronal terminal → limit subsequent exocytosis of storage vesicles containing NE [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Mechanism**: Acts as negative feedback loop [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **CNS effects**: Reduced SNS outflow + enhanced parasympathetic outflow → sedation, peripheral vasodilation, decreased CO and inotropic state, decreased HR [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Norepinephrine interactions**:
  * Acts on both α1 and α2 receptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Activates smooth muscle vasoconstriction (postsynaptic α1 and α2) but also stimulates presynaptic α2 receptors and inhibits its own release [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Selective presynaptic α2 stimulation → beneficial reduction in peripheral vascular resistance [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Most α2 agonists also stimulate postsynaptic α2 receptors → vasoconstriction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Blockade of presynaptic α2 → increased NE release → vasoconstriction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Vasodilation requires blockade of both postsynaptic α1 and α2 receptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

### 2.3. BETA RECEPTORS

* **Signal transduction**: Linked to Gs activating adenylate cyclase [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Mechanism**: Activation of adenylate cyclase → increased cAMP synthesis → initiates kinase phosphorylation cascade [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Effects on Ca²⁺ homeostasis**:
  * Greater Ca²⁺ availability for contractile activation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Increased efficacy of activator Ca²⁺ at troponin C (TnC) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Faster removal of Ca²⁺ from contractile apparatus after contraction → rapid myocardial relaxation during early diastole [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 2.3.1. Β1 RECEPTORS

* **Agonist potency**: Norepinephrine and epinephrine are equipotent [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Location**: Primarily postsynaptic membranes in heart - myocardium, SA node and ventricular conduction system [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Effects**:
  * **Chronotropic**: Increased heart rate [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Dromotropic**: Increased conduction velocity [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Inotropic**: Increased contractility [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Lusitropic**: Enhanced relaxation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 2.3.2. Β2 RECEPTORS

* **Agonist potency**: Epinephrine significantly more potent than norepinephrine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Location**: Primarily postsynaptic receptors in smooth muscle and gland cells; also found in myocytes (atrial > ventricular) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Clinical note**: Effect is increased in patients with chronic heart failure [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Effects**:
  * **Smooth muscle**: Relaxation → bronchodilation, vasodilation, relaxation of uterus (tocolysis), bladder, and gut [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Metabolic**: Stimulates glycogenolysis, lipolysis, gluconeogenesis, and insulin release [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Presynaptic β2 receptors**:
  * **Effect**: Accelerates endogenous NE release (opposite of presynaptic α2) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Clinical relevance**: Blockade inhibits NE release, similar physiologic effect as activating presynaptic α2 [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 2.3.3. Β3 RECEPTORS

* **Location**: Gallbladder, brain, adipose tissue [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Function**: Involved in lipolysis, thermogenesis in brown fat, bladder relaxation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

### 2.4. DOPAMINERGIC RECEPTORS

* **Location**: CNS, blood vessels, postganglionic sympathetic nerves [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **In CNS**: Dopamine is released as a neurotransmitter in certain brain cells and interneurons of the autonomic ganglia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 2.4.1. D1 RECEPTORS

* **Location**: Postsynaptic [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Mechanism of action**: Acts via Gs-coupled adenylate cyclase leading to increased levels of cAMP [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Effect**: Mediates vasodilation in kidney, intestine, and heart [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 2.4.2. D2 RECEPTORS

* **Location**: Preand postsynaptic [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Mechanism of action**: Acts via Gi-coupled adenylate cyclase leading to decreased levels of cAMP [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Vascular effects**: Similar to α2 receptor [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Presynaptic effects**: Inhibits NE release → vasodilation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Postsynaptic effects**: Vasoconstriction (opposite of postsynaptic D1) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Other functions**:
  * Role in antiemetic action of droperidol [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Present in zona glomerulosa of adrenal cortex → inhibits aldosterone [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Modulates extrapyramidal movement and inhibits prolactin secretion from pituitary gland [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

### 2.5. OTHER MODULATORY RECEPTORS

#### 2.5.1. ADENOSINE RECEPTORS

* **Effect**: Inhibit NE release [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Antagonists**: Blocked by caffeine and other methylxanthines [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Function**:
  * Reduction of SNS tone under hypoxic conditions when adenosine production is enhanced [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Leads to reduced NE, decreased cardiac work, reduced O2 demand [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Clinical applications: controlled hypotension, short-term bradycardia, coronary vasodilation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

#### 2.5.2. SEROTONIN RECEPTORS

* **Effect**: Depresses response of isolated blood vessels to SNS stimulation and decreases release of labeled NE [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Mechanism**: Antagonized by increasing external Ca²⁺ ion concentration [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Function**: May inhibit neuronal NE release by limiting calcium availability at nerve terminals [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Other Modulators**:
  * **Prostaglandin E2, Histamine, and Opioids**:
	* May inhibit NE release in SNS innervated tissue [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Unlikely to play physiologic role (antagonists don't increase NE release) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 2.5.3. HISTAMINE RECEPTORS

* **H1 receptors**: Negative dromotropism, coronary spasm, bronchoconstriction, intestinal contraction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **H2 receptors**:
  * Positive inotropic and chronotropic effects while depressing dromotropism [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Present in high concentrations in myocardium and cardiac conducting tissue [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Effects not blocked by β antagonism but blocked by H2 antagonists [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Also stimulates acid production in parietal cells of stomach [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

**Bottom Line:** Adrenergic receptors are divided into α, β, and dopaminergic types, each with specific subtypes and distinct signaling pathways. α1 receptors primarily mediate vasoconstriction, α2 receptors have both preand postsynaptic effects, β1 receptors affect cardiac function, and β2 receptors cause smooth muscle relaxation. Understanding these distinctions is crucial for predicting drug effects and side effects.

## 3. ADRENERGIC RECEPTOR REGULATION 












### 3.1. DYNAMIC REGULATION PRINCIPLES

* **Dynamic regulation**: Receptors are dynamically regulated [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Receptor density principle**: Number of receptors is inversely proportional to ambient concentration of catecholamines [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Tachyphylaxis**: Extended exposure to agonists reduces biologic response to catecholamines [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

### 3.2. DOWNREGULATION AND UPREGULATION MECHANISMS 

* **Clinical examples of downregulation**:
  * **Heart failure**: Increased adrenergic activity → increased plasma catecholamines → "downregulation" of myocardial β1 receptors → decreased inotropic and chronotropic response to β1 agonists [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **β2 upregulation**: β2 receptors may account for up to 40% of inotropism in failing heart (vs. 20% in normal heart) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **Tachyphylaxis to infused catecholamines**: Result of acute downregulation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Hypertension**: Reduction in numbers/sensitivity of β receptors in patients with elevated plasma catecholamines [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Pheochromocytoma**: Downregulation explains lack of correlation between plasma catecholamine levels and blood pressure elevation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **Chronic β-agonist use**: Asthma treatments like terbutaline, isoproterenol, or epinephrine can cause tachyphylaxis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Reversibility**: Downregulation is reversible upon termination of the agonist [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

### 3.3. CLINICAL CONSEQUENCES OF RECEPTOR REGULATION 

* **Withdrawal syndromes**:
  * **Propranolol withdrawal syndrome**: Acute discontinuation of β antagonist leaves receptors unopposed plus increased receptor number (supersensitivity) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **Clonidine withdrawal**: Similar (but converse) mechanism - receptors are downregulated as clonidine is an agonist. Upon withdrawal, unopposed SNS may cause rebound HTN etc. [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

💡 **Clinical Pearl: Receptor downregulation is a key mechanism explaining decreased response to both endogenous and exogenous catecholamines in various clinical scenarios** [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

**Bottom Line:** Adrenergic receptors undergo dynamic regulation, with downregulation occurring in response to persistent agonist exposure and upregulation following chronic antagonist administration. These mechanisms have important clinical implications for drug efficacy, tachyphylaxis, and withdrawal syndromes.

## 4. ADRENERGIC AGONISTS 












### 4.1. GENERAL PRINCIPLES 

* **Activity overlap**: Overlapping receptor activity complicates prediction of clinical effects [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Hemodynamic balance**: Net effect depends on dose-dependent balance between different receptor activations [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Example: Epinephrine's effect on BP depends on balance between α1-vasoconstriction, α2/β2-vasodilation, and β1-inotropic effects [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Vascular effects**:
  * α1-predominant agents → increased arterial pressure via enhanced arterial/venous vasomotor tone → increased SVR (afterload) and venous return (preload) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * β-predominant agents → modest BP decrease as reduced SVR (β2 effects) offsets increased CO (β1 effects) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

### 4.2. CLASSIFICATION OF AGONISTS

* **Direct vs. Indirect**:
  * **Direct**: Binds directly to receptor (e.g., phenylephrine) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Indirect**: Increases endogenous neurotransmitter activity through increased release or decreased reuptake of NE (e.g., ephedrine) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Clinical importance**: In patients with abnormal endogenous NE stores (e.g., on MAOIs, some antihypertensives), intraoperative hypotension should be treated with direct agonists as response to indirect agonists will be unpredictable [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

	* Typically short-acting due to metabolism by MAO, COMT [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Exaggerated response in those on MAOIs or TCAs [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Examples: Epinephrine, Norepinephrine, Dopamine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

* **Effects**:
  * Sedative, analgesic, and sympatholytic effects [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Blunts cardiovascular responses during perioperative period [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Mediated by α2 receptors in brain (locus ceruleus) and spinal cord [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Clinical uses**:
  * Reduces IV and volatile anesthetic requirements [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Reduces postoperative analgesic and sedative requirements, especially in ICU [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Useful for sedation during awake fiberoptic intubation (particularly in obese patients with OSA or bariatric surgery candidates) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Hemodynamic response**: Biphasic arterial pressure response [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Initial hypertension: Direct stimulation of vascular α2 receptors → increased SVR → HTN + reflex bradycardia (reinforced by central sympathetic withdrawal) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Later hypotension: Activation of medullary α2/imidazoline receptors alters autonomic balance [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Dosing**: Loading dose 1 mcg/kg over 10 min, followed by infusion at 0.2-0.7 mcg/kg/h [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Special considerations**: May cause hypothermia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

💡 **Clinical Pearl: Long-term use of α2-agonists leads to supersensitization and upregulation of receptors; abrupt discontinuation can cause acute withdrawal syndrome including hypertensive crisis** [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

💡 **Clinical Pearl: Withdrawal syndrome may manifest after only 48h of dexmedetomidine use when discontinued** [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

### 4.5. CATECHOLAMINES 

#### 4.5.1. EPINEPHRINE (ADRENALINE) 

* **Structure**: Endogenous catecholamine synthesized in adrenal medulla by methylation of norepinephrine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Storage**: Stored in and released from specific chromaffin cells different from those storing norepinephrine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Presentation and Uses**:
  * Clear solution (0.1-1 mg/ml) for bolus administration in asystole/anaphylaxis or by infusion in critical illness [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Can be nebulized in upper airway to reduce swelling in acute obstruction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * 1% ophthalmic solution for open-angle glaucoma [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Metered dose inhaler (280 μg) for anaphylaxis from insect stings/drugs [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Combined with local anesthetics (1:80,000-200,000) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Mechanism of action**:
  * Exerts effects via α- and β-adrenoceptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * α1 activation stimulates phospholipase C via Gq → PIP2 hydrolysis → IP3 release → increased intracellular Ca2+ [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * β-receptor activation coupled to Gs-proteins → adenylate cyclase activation → cAMP increase → specific phosphorylation depending on receptor site [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Cardiovascular effects**:
  * **β1 effects**: Increases BP, CO, myocardial O2 demand via: [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* Increased contractility and HR (increased rate of phase IV depolarization) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Increased speed and extent of myocardial relaxation (improving LV filling in early diastole) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Marked increase in cardiac output (dose-dependent) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Initial tachycardia partially attenuated over time by baroreceptor reflexes [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Propensity for atrial/ventricular tachyarrhythmias (increased conduction velocity + reduced refractory period in conduction system) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **α1 effects**: Vasoconstricts cutaneous, mesenteric, splenic, pulmonary and renal vascular beds [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Increases renin release [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Increases coronary perfusion pressure by raising aortic diastolic pressure [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **β2 effects**: Vasodilation in skeletal muscle may lower diastolic pressure [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Differential blood flow effects depend on organ-specific distribution of α1/β2 receptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Low doses (<0.02 μg/kg/min) primarily stimulate β2 receptors → vasodilation → modest BP decrease [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Higher doses (>0.1 μg/kg/min) activate α1 receptors → increased SVR and BP [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Dose-dependence**: Effects vary with dose [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Low-dose infusion: β effects predominate → increased CO, myocardial O2 consumption, coronary artery dilation, reduced arrhythmia threshold, may lower diastolic BP and PVR [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* High-dose infusion or 1mg bolus during cardiac arrest: α1 effects predominate → rise in SVR [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * When used with halothane, dose should be restricted to 100 μg per 10 minutes to avoid arrhythmias [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Should not be infiltrated into areas supplied by end arteries to avoid compromising vascular supply [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * ⚠️ Extravasation can cause tissue necrosis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Pulmonary effects**:
  * β2 stimulation relaxes bronchial smooth muscle [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Small increase in minute volume [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Potent bronchodilator though secretions may become more tenacious [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Increases pulmonary vascular resistance [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Metabolic effects**:
  * Increases basal metabolic rate [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Raises plasma glucose via glycogenolysis (liver/skeletal muscle), lipolysis, gluconeogenesis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Initially increases insulin secretion (β2 effect) often overridden by α effect inhibiting release [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Increases glucagon secretion and plasma lactate [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Augments lipase activity → increased free fatty acids → increased fatty acid oxidation and ketogenesis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Limits use in diabetes [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Increases Na+ reabsorption via direct tubular stimulation and aldosterone production [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * β2 receptors increase K+ transport into cells following initial temporary rise from liver release [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **CNS effects**: Increases MAC and peripheral pain threshold [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Renal effects**: Moderately decreases renal blood flow; increased bladder sphincter tone may cause difficulty in micturition [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Dosing**:
  * **Anaphylaxis**: IV 100-500 mcg (repeated if necessary, followed by infusion), IM 0.5 mg [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **VF/Cardiac arrest**: IV bolus 0.5-1 mg [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **Shock**: IV bolus 0.5-1 mg with or without continuous infusion (1 mg in 250 mL [4 mcg/mL]) at 2-20 mcg/min (30-300 ng/kg/min) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Pharmacokinetics**:
  * Not given orally due to inactivation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * SC absorption less rapid than IM; tracheal absorption erratic but useful in emergencies without IV access [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Metabolized by mitochondrial MAO and COMT in liver, kidney, blood to inactive metabolites (VMA and metadrenaline) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Conjugated with glucuronic acid or sulfates and excreted in urine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Short half-life (~2 minutes) due to rapid metabolism [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Special considerations**:
  * Volatile anesthetics (particularly halothane) potentiate arrhythmogenic effects [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Prior administration of adrenoceptor antagonists alters cardiovascular effects: [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* Non-selective β-blocker: β2 vasodilation blocked → unopposed α1 vasoconstriction; β1 effects attenuated → phenylephrine-like response [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* α1-blocker: Unopposed β2 vasodilation → hypotension [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* α2-blocker (e.g., cocaine): Enhances intensity and duration of cardiovascular effects by inhibiting reuptake [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

#### 4.5.2. NOREPINEPHRINE (NORADRENALINE) 

* **MOA**: Direct α1, α2 and β1 stimulation with limited β2 activity at clinical doses [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Presentation and Uses**:
  * Clear solution containing 0.2-2 mg/ml norepinephrine acid tartrate (equivalent to 0.1-1 mg/ml norepinephrine base) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Contains sodium metabisulfite preservative [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Used as IV infusion (0.05-0.5 μg/kg/min) to increase SVR [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Cardiovascular effects**:
  * Intense vasoconstriction of arterial and venous vessels [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* May cause spasm of internal mammary/radial artery grafts during CABG [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* ⚠ Can increase pulmonary HTN → precipitate RV dysfunction/failure [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	  * Inhaled selective pulmonary vasodilators (NO, prostacyclin) may help counteract this [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Increased myocardial contractility [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Pure α1 agonists decrease cardiac output by increasing LV afterload without β1-mediated contractility increase [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Increases myocardial oxygen requirements [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Less arrhythmogenic than epinephrine (useful when significant arrhythmias present) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Decreased hepatic, skeletal, renal and splanchnic blood flow when BP normal/slightly reduced [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Increases perfusion pressure to these vascular beds when arterial pressure significantly reduced (except renal, mesenteric, and peripheral) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Low-dose dopamine or fenoldopam may help preserve renal function but doesn't reduce AKI risk [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Both systolic and diastolic pressures rise; increased afterload and reflex bradycardia may prevent CO elevation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * ⚠ Extravasation can cause tissue necrosis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Comparison of systemic vs. endogenous effects**:
	* Systemic infusion: peripheral vasoconstriction, increased systolic/diastolic BP, possible reflex bradycardia, may reduce CO, increases myocardial O2 consumption, increases coronary flow, increases PVR, increases venous return through venoconstriction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Endogenous release: causes tachycardia and increased CO [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Splanchnic effects**: Renal and hepatic blood flow falls due to vasoconstriction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Uterine effects**:
  * Reduces blood flow to pregnant uterus → may cause fetal bradycardia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * May exert contractile effect and cause fetal asphyxia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Clinical uses**:
  * Agent of choice for refractory (particularly septic) shock [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Combined with methylene blue or hydroxocobalamin for vasoplegic syndrome after cardiopulmonary bypass [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Dosing**: Continuous infusion at 2-20 mcg/min (30-300 ng/kg/min) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Preferably via CVC; dilute solutions (≤20 μg/mL) can be given peripherally [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Pharmacokinetics**:
  * Pathways include Uptake 1 and Uptake 2 as described in section 1.1.2 [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Short half-life (~2 minutes) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Unlike epinephrine and dopamine, up to 25% is taken up as it passes through lungs [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Interactions**: Despite being direct-acting, should be used cautiously in patients taking MAOIs as effects may be exaggerated and prolonged [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 4.5.3. DOPAMINE 

* **Structure**: Endogenous nonselective direct and indirect adrenergic and dopaminergic agonist [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Presentation and Uses**:
  * Clear solution containing 200 or 800 mg in 5 ml with sodium metabisulfite [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Used to improve hemodynamics and urine output [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **MOA**:
  * Direct receptor activation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Indirect effects due to NE release from presynaptic sympathetic nerves [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * In addition to α/β effects, acts via D1/D2 receptors via Gs/Gi coupled adenylate cyclase affecting cAMP levels [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Dose-dependent effects** (unpredictable dose-response curve): [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **Low dose** (0.5-3 mcg/kg/min):
	* Activates DA1 receptors → dilates renal, mesenteric, splenic vessels → increases renal/splanchnic flow → promotes diuresis and natriuresis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* Not renal protective as simultaneous α1/β1 activation may counteract dopaminergic effects [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* Activates DA2 receptors → inhibits NE release [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Net effect: modest BP decrease [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Moderate doses** (3-10 mcg/kg/min):
	* Activates β1 receptors (and α1 receptors) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Increases contractility, HR, SBP, and CO [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Myocardial oxygen demand typically increases more than supply [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Higher doses** (10-20 mcg/kg/min):
	* Activates α1 receptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Increases peripheral vascular resistance [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Decreases renal blood flow [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Cardiovascular effects**:
  * Dose-dependent and vary between patients [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Lower rates (<10 μg/kg/min): β1 predominates → increased contractility, HR, CO, coronary flow [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Also stimulates endogenous NE release at direct effects [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Higher rates (>10 μg/kg/min): α effects predominate → increased SVR and venous return [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Adequate preload essential to control tachycardia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Less arrhythmogenic than epinephrine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * ⚠️ Extravasation can cause tissue necrosis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Respiratory effects**: Attenuates carotid body response to hypoxemia; increases pulmonary vascular resistance [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Splanchnic effects**: Vasodilates mesenteric vessels via D1 receptors; improved urine output may be due to inhibited proximal tubule Na+ reabsorption and improved cardiac output/BP [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **CNS effects**: Modulates extrapyramidal movement; inhibits prolactin secretion from pituitary; cannot cross blood-brain barrier (though precursor L-dopa can) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Miscellaneous**:
  * Causes nausea/vomiting via chemoreceptor trigger zone stimulation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Increases gastric transit time [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Dosing**: Continuous infusion at 1-20 mcg/kg/min [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Clinical uses**:
  * Occasionally used for acute LV dysfunction, though more predictable agents (epinephrine, norepinephrine ± milrinone) generally preferred [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Limited use in patients with pulmonary hypertension or elevated LV filling pressures [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * May cause more pronounced tachycardia than epinephrine after cardiac surgery [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Pharmacokinetics**:
  * Only administered IV, preferably via central vein [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Acts within 5 minutes with 10-minute duration [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Metabolized by MAO and COMT in liver, kidneys, plasma to inactive compounds (3,4-dihydroxyphenylacetic acid, HVA) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Metabolites excreted in urine as sulfate and glucuronide conjugates [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * ~25% converted to norepinephrine in sympathetic nerve terminals [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Half-life ~3 minutes [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Interactions**: Despite being direct-acting, effects may be significantly exaggerated and prolonged during MAOI therapy [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

💡 **Clinical Practice Note: Arterial vasodilators (e.g., sodium nitroprusside) may be used with dopamine to offset increased LV afterload, though inotrope-vasodilators (milrinone, levosimendan) are more commonly used now** [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

#### 4.5.4. ISOPROTERENOL 

* **Structure**: Pure nonselective β-agonist (low α affinity), synthetic catecholamine derived from dopamine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Presentation and Uses**:
  * Clear solution (1 mg/ml) for IV infusion; metered dose inhaler (80 or 400 μg) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * No longer used for reversible airway obstruction (associated with increased mortality) - more specific β2 agonists now used [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * 30 mg tablets rarely used [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * IV for severe bradycardia with AV block or β-blockers (0.5-10 μg/min) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Cardiovascular effects**:
  * **β1 effects**: Increases HR, contractility, and CO; SBP may increase or remain unchanged [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* Limited effect because tachycardia may reduce LV filling; SBP may not increase due to venodilation decreasing preload [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **β2 effects**: Decreases peripheral vascular resistance and diastolic BP [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Arteriolar vasodilation in renal, mesenteric, splenic, and skeletal muscle circulations [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Contributes to baroreceptor-mediated increases in HR [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * ⚠ Myocardial oxygen demand increases while supply falls → poor inotropic choice in most situations [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **Varied BP effects: β2 effects may drop SVR so increased CO insufficient to maintain BP - may actually decrease MAP** [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Myocardial O2 delivery may decrease significantly when tachycardia reduces diastolic coronary filling time and reduced diastolic BP reduces coronary perfusion [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Some coronary vasodilation occurs to attenuate this effect [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Respiratory effects**:
  * Potent bronchodilator; inhibits histamine release in lungs; improves mucous flow [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Anatomical dead space and V/Q mismatching increase → may cause systemic hypoxemia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **CNS effects**: Stimulant effects on CNS [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Splanchnic effects**: Increased mesenteric and renal blood flow [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Metabolic effects**: β effects → raised blood glucose and free fatty acids [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Historical uses**:
  * "Pharmacologic pacing" for symptomatic bradyarrhythmias/AV block (replaced by transcutaneous/transvenous pacing) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Treatment of pulmonary HTN (replaced by selective inhaled pulmonary vasodilators) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Adverse effects**: High propensity to cause SVT and VT [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Pharmacokinetics**:
  * Well absorbed orally but extensive first-pass metabolism results in low bioavailability [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Rapidly metabolized by COMT in liver [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Significant fraction excreted unchanged in urine along with conjugated metabolites [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 4.5.5. DOBUTAMINE 

* **Structure**: Racemic mixture with affinity for both β1 and β2 receptors (higher β1 selectivity) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Synthetic catecholamine derivative of isoprenaline with predominant β1 effects but small β2 effect [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Presentation and Uses**:
  * 20 ml water containing 250 mg dobutamine and sodium metabisulfite, or 5 ml water with 250 mg dobutamine and ascorbic acid [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Used for low cardiac output states: myocardial infarction, cardiac surgery, cardiogenic shock [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Also used in cardiac stress testing as alternative to exercise [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **α1 effects**: Present but minimal at infusion rates <5 μg/kg/min [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Cardiovascular effects**:
  * **Primary effect**: Increased myocardial contractility [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * β2 activation usually prevents significant BP rise (vasodilation) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Decreases pulmonary artery pressures and vascular resistance [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* Useful in patients with pulmonary arterial hypertension [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* Preferred to dopamine in PAH with elevated LV filling pressures [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* ⚠ May exacerbate V/Q mismatch → increased transpulmonary shunt → relative hypoxemia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Decreases LV filling pressure while increasing coronary blood flow [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Improves LV-arterial coupling, enhances myocardial efficiency, increases CO [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Reduces MR severity in dilated cardiomyopathy with elevated LV filling pressures [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Increases myocardial oxygen consumption [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Basis for pharmacological stress testing to detect flow-limiting coronary stenosis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Often reduces HR in acute HF/HFrEF patients [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* Improved CO and O2 delivery reduces elevated sympathetic tone [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* β2 activation decreases preload/afterload, reducing LV EDP and ESP [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * At higher rates (>5 μg/kg/min), (−) isomer progressively stimulates α1 receptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Attenuates β2-mediated vasodilation → maintains preload, afterload, BP [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Blunts baroreceptor-mediated tachycardia (though β1 effects still cause chronotropic/dromotropic effects) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Causes more pronounced tachycardia than epinephrine at equivalent cardiac index after CABG [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Direct β1 stimulation may increase heart rate, contractility, conduction velocity, and myocardial oxygen requirement [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * May precipitate arrhythmias including increased ventricular response rate in atrial fibrillation/flutter due to increased AV conduction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Splanchnic effects**: No direct effect on splanchnic circulation, though urine output may increase from improved cardiac output [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Clinical uses**:
  * Pharmacological stress testing [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Treatment of depressed myocardial contractility in sepsis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * ⚠ Despite theoretical benefits, clinical trials associate dobutamine with increased major adverse cardiac events and mortality in decompensated heart failure [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Should be avoided in patients with cardiac outflow obstruction (aortic stenosis, cardiac tamponade) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Dosing**: Infusion at 2-20 mcg/kg/min [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Pharmacokinetics**:
  * Only administered intravenously [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Rapidly metabolized by COMT to inactive metabolites conjugated and excreted in urine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Half-life ~2 minutes [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

💡 **Clinical Practice Note: Many cardiac anesthesiologists no longer use dobutamine for inotropic support due to concerning clinical data** [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

#### 4.5.6. DOPEXAMINE

  * May reduce blood pressure [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

* **Other effects**:

  * **Renal**: Increased urine output [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

  * **Respiratory**: Bronchodilation via β2 stimulation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Miscellaneous**: Tremor, headache reported [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Pharmacokinetics**:
  * Rapid clearance from blood [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

### 4.6. MIXED ADRENERGIC AGONISTS 

#### 4.6.1. EPHEDRINE 

* **Structure**: Noncatecholamine sympathomimetic [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Presentation and Uses**:
  * Tablets, elixir, nasal drops and solution for injection (30 mg/ml) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Can exist as four isomers but only L-isomer is active [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Used IV for hypotension associated with regional anesthesia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * In obstetrics now known to result in poorer cord gas pH compared to pure α-agonists, but still preferred with maternal bradycardia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Also used for bronchospasm, nocturnal enuresis, narcolepsy [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **MOA**: Both indirect (predominant) and direct actions on adrenergic receptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Indirect**: Endocytosis into nerve terminals → displaces NE from synaptic vesicles → NE release [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Direct**: Stimulation of β2 receptors → limits vasoconstrictor effect of α1 [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Also inhibits MAO actions on norepinephrine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Tachyphylaxis occurs due to depletion of presynaptic NE stores [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Ephedrine then released as false neurotransmitter → subsequent doses must be increased [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Effects**: Similar to epinephrine: increases BP, HR, contractility, and CO; bronchodilation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Differences from epinephrine**:
  * Longer duration of action [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Less potent [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Both indirect and direct actions [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Stimulates CNS (raises MAC) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Cardiovascular effects**:
  * Increases CO, HR, BP, coronary flow, myocardial O2 consumption [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * May precipitate arrhythmias [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Respiratory effects**:
  * Respiratory stimulant and bronchodilator [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Renal effects**:
  * Decreased renal blood flow and glomerular filtration rate [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Dosing**: 2.5-10 mg boluses, 0.1 mg/kg (in pediatrics) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Pharmacokinetics**:
  * Well absorbed orally, IM, and SC [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Unlike epinephrine, not metabolized by MAO or COMT → longer duration of action, elimination half-life ~4 hours [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Some hepatic metabolism but 65% excreted unchanged in urine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Interactions**:
  * Drugs blocking ephedrine uptake (e.g., cocaine) or depleting NE (e.g., reserpine) attenuate cardiovascular effects [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Use with extreme caution in patients taking MAOIs [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 4.6.2. METARAMINOL 

* **Classification**: Synthetic amine with both direct and indirect sympathomimetic actions [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

##### 4.7.1.1. SALBUTAMOL (ALBUTEROL) 

* **Classification**: Synthetic sympathomimetic with mainly β2 effects [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Presentation**:
  * Clear solution (50-500 μg/ml) for IV infusion after dilution [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	  * For bronchospasm: IV slow bolus 4mcg/kg > infusion 3-20mcg/min
  * Metered dose inhaler (100 μg) and dry powder (200-400 μg) for inhalation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	  * Usually given 8 puffs every few minutes in bronchopasm (8 puffs because of dead space)
	  * Else use 10-20mcg boluses of adrenaline

  * Solution for nebulization (2.5-5 mg/ml) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Oral preparations (syrup 0.4 mg/ml and 2, 4 or 8 mg tablets) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Uses**: Reversible lower airway obstruction; occasionally for premature labor [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Effects**:
  * **Respiratory**: Relaxes bronchial smooth muscle; reverses hypoxic pulmonary vasoconstriction (may lead to hypoxemia) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Cardiovascular**: High doses (especially IV) can stimulate β1 receptors causing tachycardia; may cause β2-mediated vasodilation and hypotension; can precipitate arrhythmias with hypokalaemia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Metabolic**: Stimulates Na+/K+ ATPase causing hypokalaemia; raises blood sugar especially in diabetics (exacerbated by concurrent steroids) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Uterine**: Relaxes gravid uterus; small amount crosses placenta [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Miscellaneous**: Direct effect on skeletal muscle may produce tremor [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Pharmacokinetics**:
  * Incomplete gut absorption with significant first-pass metabolism [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Rapid onset with inhalation or IV administration [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * 10% protein-bound with half-life of 4-6 hours `[A:12-13]`
  * Metabolized in liver to inactive 4-O-sulfate; excreted with unchanged salbutamol in urine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

* **Uses**: Treat premature labor [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 4.7.2. FENOLDOPAM 

* **Structure**: Selective D1-receptor agonist with minimal α, β, or D2 activity [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Pharmacokinetics**: Rapid onset, hepatic metabolism, urinary excretion, t1/2 5 min [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Effects**:
  * Hypotensive effects through decreased peripheral vascular resistance [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Increases renal blood flow, diuresis, and natriuresis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Exerts antihypertensive effect while maintaining renal blood flow [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Adverse effects**: Hypotension, tachycardia, flushing, dizziness, headache, nausea [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Clinical uses**:
  * Severe hypertension/hypertensive emergencies, particularly with renal impairment [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * ⚠ Formerly used in cardiac surgery and aortic aneurysm repair to prevent perioperative kidney injury, but evidence for efficacy is lacking [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Theoretically indicated for prevention of contrast-induced nephropathy, but large RCTs have not supported early promising results [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Properties**: Rapid onset, short t1/2 makes it easily titratable [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Dosing**: Initial infusion 0.1 mcg/kg/min, increased by 0.1 mcg/kg/min every 20-30 min to max 1.6 mcg/kg/min [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

**Bottom Line:** Adrenergic agonists comprise a diverse group of medications including direct-acting alpha agonists, alpha-2 agonists, catecholamines, and mixed agonists. They vary significantly in receptor selectivity, resulting in different hemodynamic profiles. Understanding these differences is essential for appropriate drug selection in specific clinical scenarios.

## 5. ADRENERGIC ANTAGONISTS 












### 5.1. ALPHA BLOCKERS 

* **Overview**: Alpha-adrenoceptor antagonists (α-blockers) prevent sympathomimetic agent actions at α-adrenoceptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Classification**:
  * **Non-selective**: Inhibit both α1 and α2 receptors (phentolamine, phenoxybenzamine) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Selective α1**: Prazosin [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Selective α2**: Yohimbine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

**Summary of α-Adrenoceptor Actions:**

| Receptor type | Action |
|---------------|--------|
| **Postsynaptic α1** | Vasoconstriction, mydriasis, bladder sphincter contraction |
| **Postsynaptic α2** | Platelet aggregation, hyperpolarization of some CNS neurons |
| **Presynaptic α2** | Inhibit norepinephrine release |

#### 5.1.1. PHENTOLAMINE

  * 10 mg phentolamine mesylate in 1 ml clear pale-yellow solution [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

  * Assessment of sympathetically mediated chronic pain [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Previously used for pulmonary hypertension [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Injection into corpus cavernosum for erectile dysfunction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Combined with norepinephrine for inotropic support in cardiac surgery [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Control excessive hypertension during pheochromocytoma resection [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

* **Effects of phentolamine**:
  * α1 antagonism (reversible) and direct smooth muscle relaxation → peripheral vasodilation and decreased BP [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * ⚠ Reflex tachycardia and postural hypotension (use cautiously with coronary stenosis) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Tachycardia augmented by α2 blockade (eliminates negative feedback for NE release) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Response magnitude depends on existing sympathetic tone [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * May cause unopposed β1/β2 activity: [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Epinephrine → pronounced tachycardia (β1) and severe hypotension (β2 vasodilation) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* Norepinephrine/ephedrine → only activate β1 as α1 actions are blocked [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **Cardiovascular**: α1-blockade → vasodilation and hypotension; α2-blockade → NE release → tachycardia and increased CO; reduces pulmonary artery pressure; vasodilation in nasal mucosa → nasal congestion `[A:7-8]`
  * **Respiratory**: Sulfites in phentolamine ampoules may cause hypersensitivity reactions/bronchospasm in susceptible asthmatics [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **GI**: Increases GI secretions and motility [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Metabolic**: May cause hypoglycemia due to increased insulin secretion [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Pharmacokinetics**: Oral route rarely used (20% bioavailability); 50% protein-bound; extensively metabolized with ~10% excreted unchanged in urine; elimination half-life 20 minutes [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 5.1.2. PHENOXYBENZAMINE 

* **Uses**: Classically used in pheochromocytoma management [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Presentation**:
  * 10 mg capsules [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

* **Uses**:
  * Pre-operative management of pheochromocytoma (allows intravascular compartment expansion) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

  * Hypertensive crises [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

  * IV administration via central cannula (1 mg/kg/day as slow infusion in at least 200 ml 0.9% saline) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

* **Properties**:
  * Irreversibly binds to α1/α2 receptors (selectivity ratio ~100:1) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

  * Prolonged half-life provides sustained action [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Slow onset (requires structural modification in situ to become active) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

* **Pharmacokinetics**:
  * Incompletely and variably absorbed from gut (oral bioavailability ~25%) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Maximum effect at 1 hour following IV dose [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Plasma half-life ~24 hours; effects may persist 3 days while new α-adrenoceptors synthesized [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Metabolized in liver, excreted in urine and bile [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 5.1.3. PRAZOSIN AND OTHER Α1 ANTAGONISTS

### 5.3. MIXED ANTAGONISTS 

#### 5.3.1. LABETALOL 

* **Structure**: Third-generation agent composed of 4 stereoisomers with varying receptor effects [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Blocks α1, β1, and β2 receptors (α:β blockade ratio ~1:7) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * One stereoisomer: α1 antagonist [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * One stereoisomer: Non-selective β blocker [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Remaining two: No appreciable adrenergic effect [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Name indicates both α and β blocking properties [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Contains two asymmetric centers → mixture of four stereoisomers in equal proportions [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * (SR)-stereoisomer probably responsible for α1 effects [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * (RR)-stereoisomer likely confers β-blockade [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Ratio of α1:β-blocking effects depends on administration route: 1:3 for oral, 1:7 for IV [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Unique property**: Despite non-selective β-blocking effects, has partial β2 agonist activity → vasodilation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Hemodynamic effects**:
  * Reduces peripheral vascular resistance and arterial BP [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * HR, CO usually slightly depressed or unchanged [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * No reflex tachycardia due to combined α/β effects (beneficial in coronary artery disease) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Presentation and Uses**:
  * 50-400 mg tablets and colorless solution (5 mg/ml) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Used for hypertensive crises and to facilitate hypotension during anesthesia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * IV dose 5-20 mg titrated to max 200 mg [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Oral for hypertension with angina and during pregnancy (100-800 mg bd, max 2.4 g daily) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Mechanism of Action**:
  * Selective α1-blockade → peripheral vasodilation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * β-blockade prevents reflex tachycardia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Reduces myocardial afterload and oxygen demand (beneficial in angina) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Pharmacokinetics**: Peaks 5 min after IV dose, elimination t1/2 ~6h [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Well absorbed from gut but extensive first-pass metabolism gives 25% oral bioavailability [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Increases markedly with age and when taken with food [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * 50% protein-bound [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Hepatic metabolism produces several inactive conjugates [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Dosing**: 2.5-10 mg IV over 2 min, repeated 5-20 mg IV at 10 min intervals [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

### 6.1. PHOSPHODIESTERASE INHIBITORS 

* **Overview**: Phosphodiesterases (PDE) are structurally related enzymes that hydrolyze second messengers cAMP and cGMP to terminate their physiologic effects [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * At least 7 different isoform subtypes have been identified [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * The PDE inhibitors currently in clinical use are somewhat isoenzyme selective at lower doses, but this selectivity is lost when higher doses are administered [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Myocardium and Vascular smooth muscle**: Contain PDE III - bound to sarcoplasmic reticulum and cleaves cAMP to AMP [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Selective inhibition alters intracellular Ca²⁺ regulation → enhances myocardial contractility without affecting catecholamine release or activating β1 receptors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

#### 6.1.1. MILRINONE 

* **Classification**: PDE III inhibitor - 15-20x more potent than inamrinone (first clinically used PDE III inhibitor - but causes profound thrombocytopenia) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Presentation**: Yellow solution (1 mg/ml) that can be stored at room temperature [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Uses**: Short-term management of cardiac failure [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Dose**:
  * Loading doses of 25 or 50 µg/kg [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Infusion rates ranging between 0.375 and 0.75 µg/kg/min [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Mechanism and Effects**:
  * **Contractility enhancement**: Inhibits PDE III which degrades cAMP → increasing intracellular cAMP → increased phosphorylation of calcium influx channels via protein kinase A → promotes actin-myosin cross bridging → enhanced contractility [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **Improved relaxation**: Stimulates Ca²⁺ reuptake by phosphorylating phospholamban (major sarcoplasmic reticulum Ca²⁺-ATPase regulatory protein) → enhances rate and extent of myocardial relaxation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **Vasodilation**: Acts on cAMP synthesis in vascular smooth muscle + blocks cGMP metabolism → peripheral arterial vasodilation (greater than β2 agonists) → reduced LV afterload → increased CO + improved LV-arterial coupling + improved mechanical efficiency [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* Vasodilation reduces preload + afterload → reduced myocardial O2 demand [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* May also reduce pulmonary vascular resistance (in IV or inhalational formulations) → helpful in pulmonary HTN and RV dysfunction but may increase intrapulmonary shunt → hypoxemia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **Hemodynamic profile**: "Inodilator" - MAP may be maintained or modestly reduced (provided that IV volume is adequate) as increases in CO compensates for reductions in afterload [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **Heart rate effects**: Less pronounced increases in HR compared to beta agonists but may precipitate malignant VTs because of increased intracellular cAMP and Ca²⁺ concentrations [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **Coronary effects**: Dilates native epicardial coronary arteries and arterial bypass conduits; potential to exert anti-ischemic effects in patients undergoing coronary artery surgery [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Clinical uses**:
  * For patients who have received chronic beta blockade (as alternative to dobutamine) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * In patients without severely reduced SBP [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Used with vasoconstrictor to counteract peripheral vasodilation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Combined with β1 agonist when weaning patients with preexisting LV systolic dysfunction from cardiopulmonary bypass [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Pharmacokinetics**:
  * ~70% protein-bound [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Elimination half-life 1-2.5 hours [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * 80% excreted unchanged in urine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Reduce dose in renal failure [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Limitations**: Has long-term adverse effects - OPTIME-CHF trial found it was not superior to placebo in terms of reduction of medium-term mortality or HF hospitalizations; associated with increased rates of arrhythmias and hypotension [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * PDE III inhibitors are contraindicated for treatment of chronic HFrEF but useful for treatment of acute LV systolic dysfunction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

	* High oral bioavailability (>90%) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* ~50% protein-bound [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

	* Avoid certain SSRIs (fluvoxamine) as aminophylline levels may rise sharply [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* CYP450 inducers (phenytoin, carbamazepine, barbiturates, rifampicin) increase clearance → may need higher dose [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Enoximone**: [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * **Classification**: Selective PDE III inhibitor; imidazolone derivative [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Presentation**: Yellow liquid (pH 12) for IV use containing 5 mg/ml; supplied in propyl glycol and ethanol; store at 5-8°C [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Uses**: Heart failure and low cardiac output after cardiac surgery [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]] [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Mechanism of action**:
	* Prevents cAMP and possibly cGMP degradation in cardiac and vascular smooth muscle [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Increases cAMP within myocardium → increases slow Ca2+ inward current during cardiac action potential [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Increases Ca2+ release from intracellular stores and near contractile proteins → positive inotropic effect [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Interferes with Ca2+ flux into vascular smooth muscle → vasodilation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Effects**:
	* "Inodilator" due to positive inotropic and vasodilator effects [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* In heart failure, increases CO ~30% while decreasing end diastolic filling pressures ~35% [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Maintains myocardial oxygen extraction ratio via reduced ventricular wall tension and improved coronary perfusion [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* BP may remain unchanged or fall; HR unchanged or slight rise; arrhythmias rare [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Shortens atrial, AV node and ventricular refractoriness [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* In ischemic heart disease, reduced coronary perfusion pressure and increased HR may outweigh improved myocardial flow → further ischemia `[A:16-17]`
  * **Adverse effects**: Agranulocytosis reported [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Administration and dosing**:
	* Dilute with equal volume of water/0.9% saline in plastic syringes (crystal formation in glass) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Administer as infusion (5-20 μg/kg/min), possibly preceded by 0.5 mg/kg loading dose (repeatable to max 3 mg/kg) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Unlike catecholamines, may take 30 minutes to act [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **Pharmacokinetics**:
	* Well absorbed orally but extensive first-pass metabolism makes oral route ineffective [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* ~70% protein-bound [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Hepatic metabolism to renally excreted active sulfoxide metabolite (10% of enoximone's activity, 7.5-hour half-life) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Small amounts excreted unchanged in urine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Terminal half-life 4.5 hours by infusion [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Wide therapeutic ratio with low toxicity risk [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Reduce dose in renal failure [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

### 6.2. CALCIUM SENSITIZERS 

#### 6.2.1. LEVOSIMENDAN 

* **Classification**: Myofilament Ca²⁺ sensitizer [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Clinical evidence**: Initially touted as a treatment for acute decompensation of chronic HFrEF, but did not reduce death or major adverse cardiac events compared with dobutamine; produces rapid improvement in symptoms of acute decompensated heart failure but increases risk of cardiovascular-related complications [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **MOA**: Inotropic agent, calcium sensitizer, and vasodilator through 3 major mechanisms [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Binds to troponin C and stabilizes the Ca²⁺-bound conformation of the regulatory protein in a Ca²⁺-dependent manner → prolongs interaction between actin and myosin filaments → enhances rate and extent of myocyte contraction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Potent PDE III inhibitor → positive inotropic and lusitropic effects causing systemic, pulmonary and coronary vasodilation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Opens ATP-dependent K⁺ channels → vasodilator properties and additional benefit of myocardial protection against ischemic injury [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Decreases LV filling pressures, MAP, pulmonary and systemic vascular resistances and increases CO in HFrEF [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Improves LV-arterial coupling and mechanical efficiency with minimal increases in HR and myocardial O2 demand [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Effects**:
  * Increases cardiac contractility and output, stroke volume, heart rate and coronary blood flow [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Decreases systemic vascular resistance, blood pressure and myocardial oxygen consumption [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Can produce atrial fibrillation [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Advantages**:
  * Effective in patients on chronic beta-blockers [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * No major electrolyte shifts associated with arrhythmogenic profile of other classical inotropes [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * No tachyphylaxis [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Long half-life (7-9d) - useful in weaning off inotropes [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Has a biologically active metabolite that most likely contributes to the parent drug's more prolonged hemodynamic effects compared with catecholamines or PDE III inhibitors [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Pharmacokinetics**:
  * Oral bioavailability 85% [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Highly protein-bound [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Extensively metabolized in liver to active metabolites [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Excreted in bile and urine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Adjust dose in renal impairment [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Administration**: Given by IV infusion, may follow initial loading dose [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

### 6.3. VASOPRESSIN 

* **Structure**: Antidiuretic hormone (ADH), peptide hormone released from posterior pituitary that regulates water reabsorption in kidney and exerts potent hemodynamic effects [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Vasopressinergic mechanisms are essential for maintaining arterial pressure when sympathetic nervous system or renin-angiotensin-aldosterone axis dysfunction is present [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Receptor subtypes**: 3 subtypes of vasopressin receptors - all are 5-subunit helical membrane proteins coupled to G proteins [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **V1 receptors** (primary cardiovascular effect): On cell membrane of vascular smooth muscle [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
	* Activation → phospholipase C activated → hydrolysis of inositol 4,5-bisphosphate (PIP2) to inositol 1,4,5-triphosphate (IP3) and diacylglycerol (DAG) → secondary messengers increase intracellular Ca²⁺ concentration → vasoconstriction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **V2 receptors** (renal): On renal collecting duct cells → increase reabsorption of free water [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * **V3 receptors** (pituitary): Autocoid modulator [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Dosing**: 0.03u/min - 2.4u/hr [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Should not be used at doses higher than 0.04 U per minute and should be administered only in patients with a high level of cardiac output [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Exogenous administration of vasopressin does not substantially affect arterial pressure in healthy subjects because activation of central V1 receptors in the area postrema enhances baroreceptor-mediated inhibition of efferent sympathetic nervous outflow, negating the elevated system vascular resistance resulting from V1-mediated arterial vasoconstriction [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Clinical applications**: `[A:14-15]` `[B:11-12]` [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Vasopressin deficiency to support arterial pressure [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Patients on ARB/ACEI [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Intraoperative hypotension refractory to catecholamines and sympathomimetics [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * During general/neuraxial anesthesia (which reduces sympathetic nervous tone → decreased plasma stress hormone including vasopressin) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Acute vasodilatory states - anaphylaxis, sepsis, vasoplegia, neurogenic shock [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Part of AHA ACLS as bolus IV administration for VF, PEA or asystole [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Preferred in RV failure due to neutral effect on pulmonary resistances and pressures [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Adverse effects**: Has more unfavorable adverse effects than norepinephrine [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Higher doses may produce mesenteric ischemia, peripheral vascular insufficiency, and cardiac arrest, as the drug causes pronounced vasoconstriction of cutaneous, skeletal muscle, splanchnic, and coronary vascular beds concomitant with reduced perfusion of and oxygen delivery to these tissues [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]

### 6.4. CARDIAC GLYCOSIDES 

#### 6.4.1. DIGOXIN 

* **Source**: Only oral option of positive inotropic drugs for mild-moderate HFrEF; found in "foxglove" (digitalis purpurea) [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **MOA**: Enhances contractile function but the strength of the inotropic effect is relatively minor compared to other drugs [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Binds to alpha subunit of the sarcolemmal Na⁺/K⁺ ATPase on its extracellular surface → reversible inhibition [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * This binding is affected by increases in extracellular K⁺; K⁺ inhibits digitalis-Na⁺/K⁺ ATPase → increases in intracellular Na⁺ reduces the extrusion of Ca²⁺ from the myoplasm by the sarcolemmal reticulum → indirectly increasing Ca²⁺ availability → enhances myocardial contractility [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Similar to the Treppe ("staircase") physiologic phenomenon, in which a rapid increase in heart rate causes a delay in Na⁺-K⁺ ATPase activity, leading to a transient increase in intracellular Na⁺ concentration and enhanced contractile force mediated by favorable Na⁺-Ca²⁺ exchange [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Net effects**:
  * Increased myocardial contractility [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Associated decline in LV preload, afterload, LV wall tension and myocardial O2 demand in HFrEF → reducing chronically elevated sympathetic nervous system activity [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* Thus, it has a propensity to cause arrhythmias including sinus bradycardia or arrest, AV conduction delays, and secondor third-degree heart block [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
	* But toxic levels of digitalis glycosides may paradoxically increase sympathetic nervous system tone and precipitate the development of ventricular tachyarrhythmias [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
  * Profound alterations in electrophysiology - as it binds to Na⁺/K⁺ ATP channels which maintain resting membrane potential [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Evidence**: Reduces morbidity and mortality in HFrEF but no effect on cardiovascular mortality and HF hospitalizations in HFpEF [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Limitations**: Low therapeutic ratio and narrow margin of safety [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]] [[MMed_Anaesthesiology_Part_B_Syllabus#Cardiovascular system|ⓘ]]
* **Note**: Tachyphylaxis does not occur [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

### 6.5. OTHER INOTROPIC AGENTS 

#### 6.5.1. GLUCAGON 

* **Source**: Polypeptide secreted by pancreatic α-cells [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Mechanism**: Activates glucagon receptors via G-protein-mediated mechanisms → stimulates adenylate cyclase → increases intracellular cAMP [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Clinical role**: Limited use in cardiac failure; occasionally used for β-blocker overdose [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Dosing**: Initial bolus 10 mg followed by infusion up to 5 mg/hr [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Adverse effects**: Hyperglycemia and hyperkalemia may complicate use [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 6.5.2. CALCIUM 

* **Use**: IV Ca2+ salts often improve BP briefly but should be restricted to: [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Circulatory collapse due to hyperkalemia [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
  * Ca2+ channel antagonist overdose [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

#### 6.5.3. THYROID HORMONES 

* **Effects**: T4 and T3 have positive inotropic and chronotropic effects via intracellular mechanisms [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]
* **Clinical use**: Only used to treat hypothyroidism [[mmed_anaes_part_a_syllabus#2.2 Core Anaesthetic Drugs|ⓘ]]

**Bottom Line:** Non-adrenergic cardiovascular drugs include phosphodiesterase inhibitors (milrinone), calcium sensitizers (levosimendan), vasopressin, and cardiac glycosides (digoxin). Each has a unique mechanism of action, hemodynamic profile, and clinical application. Understanding their distinct properties allows for optimized selection in specific cardiovascular conditions.
